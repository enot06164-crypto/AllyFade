# Ally Fade

Клиентский Java-мод для **Mindustry v8 (build 160.7)**. Когда союзные летающие юниты
перекрывают центральную область обзора камеры, мод плавно делает их полупрозрачными.
При удалении от центра непрозрачность плавно восстанавливается.

Мод меняет **только отрисовку**. Здоровье, характеристики, команды, принадлежность
к команде, физика и поведение юнитов не затрагиваются.

## Что реализовано

- Прозрачность считается для каждого экземпляра юнита отдельно, по положению
  камеры, а не по расстоянию до юнита игрока.
- Обрабатываются только союзные летающие юниты (`UnitType.flying`) в видимой
  области камеры.
- Вражеские юниты, союзные наземные и морские юниты, постройки, снаряды и
  эффекты мира не затрагиваются.
- Прозрачность применяется ко всему визуальному представлению юнита: корпус,
  оружие, двигатели и их спрайты, тени, щиты, статусные эффекты, дополнительные
  части и переносимые объекты.
- По умолчанию **управляемый игроком юнит не становится прозрачным**. Это можно
  изменить отдельным переключателем.
- Настройки сохраняются между запусками и имеют кнопку сброса к значениям по
  умолчанию.

## Установка

1. Соберите мод:

   ```bash
   ./gradlew build
   ```

   Готовый файл: `build/libs/AllyFade.jar`.

2. Скопируйте `AllyFade.jar` в папку модов Mindustry:

   - Linux: `~/.local/share/Mindustry/mods/`
   - Windows: `%APPDATA%\\Mindustry\\mods\\`
   - macOS: `~/Library/Application Support/Mindustry/mods/`

3. Запустите Mindustry, откройте **Модификации**, включите `Ally Fade` и
   перезапустите игру (Java-моды загружаются при старте).

Мод не изменяет файлы установленной игры и не содержит библиотек Mindustry/Arc
внутри JAR: они подключены как `compileOnly`.

## Настройки

**Настройки → Ally Fade**:

| Настройка | По умолчанию | Описание |
|---|---:|---|
| Включить Ally Fade | вкл. | Полное включение/выключение эффекта |
| Минимальная непрозрачность | 25% | Непрозрачность в центре обзора |
| Размер центральной зоны | 4% | Радиус полностью прозрачной зоны, % от меньшей стороны обзора |
| Размер переходной зоны | 16% | Ширина плавного перехода; полная непрозрачность на 4% + 16% = 20% |
| Плавность перехода | 50% | Форма кривой: 0% — линейно, 50% — smoothstep, 100% — smootherstep |
| Учитывать размеры юнитов | вкл. | Крупные спрайты начинают fade раньше |
| Не делать прозрачным юнита игрока | вкл. | Управляемый вами юнит остаётся полностью непрозрачным |

Радиусы задаются в процентах от меньшей стороны **текущего вида камеры**, поэтому
корректно масштабируются при изменении разрешения и зума.

Кнопка **«Сбросить по умолчанию»** — стандартная кнопка таблицы настроек
Mindustry; она сбрасывает все параметры этой страницы.

## Техническая архитектура

Mindustry v8 не предоставляет события «перед/после отрисовки конкретного юнита» и
не имеет поля `Unit.alpha`. Поэтому используются два согласованных хука:

1. **`FadeBatch`** — подкласс `arc.graphics.g2d.SpriteBatch`, установленный в
   `Core.batch`. В Mindustry все спрайты, заливки, линии, тени, щиты и эффекты
   отрисовываются через packed-цвет батча. `FadeBatch` переопределяет
   `setPackedColor`/`getPackedColor`: альфа вершины умножается на текущий fade,
   а `getPackedColor` возвращает исходный цвет, чтобы вложенные `Draw.color` /
   `Draw.alpha` не умножали прозрачность повторно.
2. **`FadeDrawGroup`** — подкласс `EntityGroup<Drawc>`, установленный в
   `Groups.draw`. `Renderer.draw()` вызывает `Groups.draw.draw(Drawc::draw)`.
   Обёртка на один кадр задаёт fade для конкретного юнита, вызывает исходный
   draw-callback (вместе со статусными эффектами и всем `UnitType.draw`), затем
   гарантированно восстанавливает fade в `finally`. Камера и `EntityGroup`
   по-прежнему отсекают невидимые объекты.

При замене `Groups.draw` сохраняется исходный `EntityIndexer` из `Groups.init()`
(через рефлексию) и переиндексируются уже существующие записи. Это важно:
Mindustry удаляет сущности по сохранённому индексу группы, и потерянный indexer
оставлял бы освобождённые эффекты в списке отрисовки.

Расчёт (`FadeCalculator`) не создаёт объектов и не ищет юнитов по карте:
используется уже существующий список отрисовки. На кадр один раз читаются
настройки, далее на каждый видимый `Drawc` выполняется несколько арифметических
операций. Позиции сравниваются в мировых единицах с `Camera.width/height`, что
автоматически учитывает разрешение и зум. `Smoothstep`/`smootherstep` даёт
непрерывное восстановление непрозрачности.

## Сборка и зависимости

- Java 17
- Gradle wrapper включён (`./gradlew`)
- Зависимости: `com.github.Anuken.Mindustry:core:v160.7` и
  `com.github.Anuken.Arc:arc-core:v160.7` с JitPack, `compileOnly`.
- Версия игры задаётся в `build.gradle` (`-PmindustryVersion=...`).

## Проверка

Проверено на Mindustry **160.7**:

- проект собирается командой `./gradlew build`;
- JAR загружается игрой, страница настроек отображается и локализована;
- союзные летающие юниты в центре получают alpha `0.25`, на удалении — `1.0`;
- управляемый юнит при включённом переключателе остаётся `1.0`; при выключении
  переключателя тот же юнит получает `0.25`, после включения снова `1.0`;
- союзный наземный юнит и вражеский летающий юнит остаются `1.0`;
- настройки (например, изменённый размер центральной зоны) сохраняются после
  перезапуска игры;
- в логе нет исключений и ошибок отрисовки; в игре наблюдалось ~180 FPS.

## Структура

```
AllyFade/
├── build.gradle
├── settings.gradle
├── mod.hjson
├── gradlew / gradlew.bat
├── gradle/wrapper/
└── src/main/
    ├── java/allyfade/
    │   ├── AllyFadeMod.java      точка входа и страница настроек
    │   ├── FadeSettings.java     ключи, значения по умолчанию, снимок настроек
    │   ├── FadeCalculator.java   расчёт alpha без аллокаций
    │   ├── FadeBatch.java        подмена alpha на уровне SpriteBatch
    │   ├── FadeDrawGroup.java    per-unit область действия fade
    │   └── FadeRenderer.java     установка хуков и сохранение indexer
    └── resources/bundles/
        ├── bundle.properties
        └── bundle_ru.properties
```

> В Mindustry v8 пользовательские bundle-файлы модов должны находиться в
> `bundles/`, а не в корне JAR. Это учтено в проекте.
